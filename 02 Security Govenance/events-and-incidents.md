# Security Events and Incidents

## What Is a Security Event?

A security event is an observable occurrence involving a system, network, application, or user.

An event may be routine, suspicious, or potentially harmful.

### Examples

* A user logs in
* A firewall blocks a connection
* An account experiences repeated failed login attempts
* An antivirus program detects a suspicious file
* A system administrator changes a configuration

Not every security event is an incident.

## What Is a Security Incident?

A security incident is an event or series of events that threatens, or actually affects, the confidentiality, integrity, or availability of information or systems.

An incident may violate security policies or require a coordinated response.

### Examples

* Unauthorized access to sensitive information
* Malware affecting company computers
* An account being used without permission
* Unauthorized changes to important records
* A denial-of-service attack disrupting a service

## Event vs. Incident

### Event

Something happened and may need to be reviewed.

### Incident

Something happened that requires security response because it threatens or affects protected systems, information, or operations.

The exact definition depends on the organization's policies and incident criteria.

## Why Classification Matters

Organizations need to distinguish routine activity from potential incidents so they can prioritize investigation and response.

Monitoring systems and security personnel help determine whether an event requires escalation.

## CC Exam Tips

* An event does not automatically mean a security incident occurred.
* A confirmed or suspected harmful security occurrence may require incident-response procedures.
* Follow the organization's reporting and escalation rules.

## What I Learned

Security events are occurrences that may need monitoring or investigation. Security incidents are events that require a response because they threaten or affect security.
