# Adequate Security

## What it means

Adequate security means using security measures that are appropriate for the level of risk and the potential harm that could result from losing, misusing, accessing, or changing information without authorization.

In simple terms:

> **The amount of security should match the level of risk.**

## Example

A public grocery list does not require the same level of protection as a database containing customer financial information.

The financial database has a much greater potential impact if it is compromised, so it should have stronger security controls.

## Factors to Consider

When deciding what security is adequate, an organization can consider:

- How sensitive the information is
- How valuable the information is
- How likely a threat is to occur
- How much damage could result
- What security controls are already in place

## Important Idea

Adequate security does **not** necessarily mean using the maximum possible security everywhere.

Security should be **commensurate with the risk**.

### Remember

**More risk or greater potential harm = stronger protection may be needed.**
