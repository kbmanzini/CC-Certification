# Technical Controls

## What They Are

Technical controls are security controls that use **technology** to protect systems, networks, applications, and information.

In simple terms:

> **Technical controls = Technology used for security**

---

## Examples

Common technical controls include:

- Firewalls
- Encryption
- Multi-factor authentication
- Access control systems
- Antivirus or endpoint protection
- Intrusion detection systems
- Intrusion prevention systems
- Network segmentation
- Security monitoring
- Logging systems

---

## Example

A firewall blocks unauthorized network traffic from reaching a server.

Because technology is being used to provide the protection, the firewall is a technical control.

---

## Technical Access Controls

Technical controls can determine whether users and systems are allowed to access resources.

Examples include:

- User authentication
- File permissions
- Role-based access control
- Multi-factor authentication
- Account restrictions

---

## Technical Controls and Defense in Depth

Technical controls can be combined with administrative and physical controls.

### Example

A company protects a server with:

**Administrative:**
A policy requires authorized access only.

**Physical:**
The server is kept in a locked room.

**Technical:**
Authentication and firewall rules restrict access.

Using multiple layers creates defense in depth.
