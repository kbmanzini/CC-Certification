# Security Controls

## What They Are

Security controls are safeguards used to protect systems, information, people, and organizations from security risks.

In simple terms:

> **Security controls = Safeguards that reduce security risk**

---

# Three Main Types

Security controls can be grouped into three broad categories:

1. Administrative
2. Technical
3. Physical

---

## Administrative Controls

Administrative controls use:

- Policies
- Procedures
- Training
- Management decisions
- Organizational processes

### Example

A policy requires employees to complete security awareness training.

---

## Technical Controls

Technical controls use technology to provide protection.

Examples:

- Firewalls
- Encryption
- Antivirus or endpoint protection
- Access controls
- Multi-factor authentication
- Intrusion detection systems

---

## Physical Controls

Physical controls protect physical locations and equipment.

Examples:

- Locks
- Security guards
- Cameras
- Fences
- Badge readers
- Barriers

---

# Defense in Depth

Defense in depth means using multiple layers of security controls instead of depending on one control.

### Example

A server might be protected by:

1. A locked server room
2. Network firewall rules
3. Authentication
4. Access permissions
5. Monitoring and logging

If one control fails, other controls may still provide protection.

---

# Why Controls Matter

Security controls can help:

- Reduce risk
- Prevent unauthorized access
- Detect security events
- Limit damage
- Support recovery
- Protect information

---

## CC Exam Tip

Remember the three broad categories:

**Administrative = Rules**

**Technical = Technology**

**Physical = Physical protection**
