# Logical vs. Physical Access Controls

## Logical Access Controls

Logical access controls use technical mechanisms to control access to digital resources.

Examples:

- User accounts
- Passwords
- MFA
- File permissions
- Access control lists
- Security groups
- Application permissions

### Key Question

> Can this identity access the digital resource?

---

## Physical Access Controls

Physical access controls protect buildings, rooms, equipment, and other physical resources.

Examples:

- Door locks
- Badge readers
- Security guards
- Gates
- Security cameras
- Fences

### Key Question

> Can this person physically enter the protected area?

---

# Comparison

| Logical | Physical |
|---|---|
| Protects digital resources | Protects physical resources |
| Passwords | Door locks |
| MFA | Badge readers |
| File permissions | Security guards |
| Access control lists | Gates |

---

## Example

A person may have a valid username and password but still be unable to physically enter a server room.

Likewise, someone may be able to enter a building but still lack authorization to access a particular computer system.

---

## Memory Trick

**Logical = Digital**

**Physical = Building/Equipment**
