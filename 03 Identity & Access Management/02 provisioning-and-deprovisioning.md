# Provisioning and Deprovisioning

## Provisioning

Provisioning is the process of creating an identity and providing the access required for authorized responsibilities.

### Common Provisioning Tasks

- Create the account
- Assign the correct role
- Grant required permissions
- Enroll MFA
- Provide approved application access
- Document the access

### Example

A new employee joins the IT help desk.

The organization:

1. Creates the employee's account
2. Assigns the help desk role
3. Grants access to approved support systems
4. Configures authentication

This is provisioning.

---

## Deprovisioning

Deprovisioning is the process of removing access when it is no longer required.

### Common Deprovisioning Tasks

- Disable the account
- Remove permissions
- Revoke sessions or tokens
- Remove application access
- Recover company devices when appropriate
- Document the change

### Example

An employee leaves the company.

The organization should disable the account and remove access to company systems.

---

## Why Timing Matters

Access should be removed promptly when authorization ends.

Leaving an account active creates an unnecessary opportunity for unauthorized access.

---

## Provisioning vs. Deprovisioning

| Provisioning | Deprovisioning |
|---|---|
| Creates access | Removes access |
| Used when access is needed | Used when access is no longer needed |
| Common for new employees | Common for departing employees |

### Memory Trick

**Provision = Provide**

**Deprovision = Remove**
