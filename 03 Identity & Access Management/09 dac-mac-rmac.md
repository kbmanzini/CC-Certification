# DAC, MAC, and RBAC

## Discretionary Access Control (DAC)

DAC allows the owner of a resource to decide who can access it.

### Think:

**Owner decides**

### Example

A user owns a shared folder and chooses which coworkers can access it.

---

## Mandatory Access Control (MAC)

MAC uses centrally enforced security rules to determine access.

### Think:

**Mandatory rules decide**

### Example

A system uses security classifications and authorization levels to determine whether a user can access information.

---

## Role-Based Access Control (RBAC)

RBAC assigns permissions to roles.

### Think:

**Role decides**

### Example

Everyone assigned to the accounting role receives the permissions required for approved accounting tasks.

---

# Quick Comparison

| DAC | MAC | RBAC |
|---|---|---|
| Owner decides | Security rules decide | Role determines access |
| Resource-owner control | Centralized enforcement | Job-function focused |
| Flexible | Strictly controlled | Efficient for organizations |

---

# Exam Tips

If the question says:

**"The owner chooses who can access the file."**

→ **DAC**

**"Access depends on security classification."**

→ **MAC**

**"Permissions are assigned based on job function."**

→ **RBAC**

---

# Memory Trick

**DAC = Discretion of the owner**
