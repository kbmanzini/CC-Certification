# Identity Lifecycle Management

## Overview

Identity lifecycle management is the process of managing an identity from creation through removal.

A typical identity lifecycle is:

**Define → Provision → Review → Deprovision**

Organizations use identity lifecycle management to make sure users have appropriate access throughout their time with the organization.

---

## Roles Definition

Before access is granted, an organization should determine what role the person has and what access that role requires.

### Example

A new employee is hired as a help desk technician.

They may need access to:

- Help desk ticketing
- Password-reset tools
- User support systems

They probably do not need access to:

- Payroll
- Executive records
- HR systems

Defining roles helps prevent unnecessary permissions.

---

## Provisioning

Provisioning is the process of creating an identity and granting appropriate access.

Examples:

- Creating a user account
- Assigning a role
- Granting application access
- Enrolling authentication methods
- Assigning appropriate permissions

### Memory Trick

**Provision = Provide access**

---

## Access Review

Organizations should periodically review user access.

An access review can identify:

- Excessive permissions
- Unused accounts
- Outdated permissions
- Former employees with access
- Users who changed jobs but retained old permissions

---

## Deprovisioning

Deprovisioning is the process of removing access when it is no longer needed.

This can occur when:

- An employee leaves
- A contractor's assignment ends
- A user changes roles
- An account is no longer required

### Example

When an employee leaves an organization, their account should be disabled and unnecessary access removed.

### Memory Trick

**Deprovision = Remove access**

---

## Why Identity Lifecycle Management Matters

Poor identity management can lead to:

- Unauthorized access
- Orphaned accounts
- Privilege creep
- Data exposure
- Increased attack surface

---

## Key Terms

| Term | Meaning |
|---|---|
| Identity lifecycle | Managing identity from creation to removal |
| Role definition | Determining what access a role needs |
| Provisioning | Creating identity and granting access |
| Access review | Checking whether access is still appropriate |
| Deprovisioning | Removing access |

---
