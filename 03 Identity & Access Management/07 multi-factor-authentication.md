# Multi-Factor Authentication (MFA)

## Definition

Multi-Factor Authentication (MFA) uses multiple authentication factor categories to verify identity.

The three common factor categories are:

1. Something you know
2. Something you have
3. Something you are

---

## Something You Know

Information the user knows.

Examples:

- Password
- PIN
- Passphrase

---

## Something You Have

Something the user possesses.

Examples:

- Security token
- Authentication device
- Smart card
- Hardware security key

---

## Something You Are

A biometric characteristic.

Examples:

- Fingerprint
- Facial characteristics
- Other biometric characteristics

---

## MFA Example

A user signs in using:

1. A password
2. A security token

The password is:

**Something you know**

The token is:

**Something you have**

Because they are different factor categories, this is MFA.

---

## Important Exam Point

Two passwords are generally still the same factor category.

For example:

Password + PIN

Both are:

**Something you know**

Therefore, they are not two different authentication factor categories.

---

## Why MFA Matters

MFA can reduce the risk of account compromise when one authentication factor is stolen, guessed, or exposed.
