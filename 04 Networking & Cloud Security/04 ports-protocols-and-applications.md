# 04 – Ports, Protocols, and Applications

## What are ports?
A port number helps a computer deliver network traffic to the correct service or application.

## Common Ports

| Port | Protocol | Purpose |
|---|---|---|
| 20/21 | FTP | File transfer |
| 22 | SSH | Secure remote administration |
| 23 | Telnet | Unencrypted remote terminal |
| 25 | SMTP | Sending email |
| 53 | DNS | Name resolution |
| 67/68 | DHCP | Automatic network configuration |
| 80 | HTTP | Unencrypted web traffic |
| 110 | POP3 | Email retrieval |
| 123 | NTP | Time synchronization |
| 143 | IMAP | Email access |
| 161/162 | SNMP | Network monitoring |
| 443 | HTTPS | Encrypted web traffic |
| 3389 | RDP | Remote Desktop Protocol |

## Secure Protocols

- HTTPS: Protects web traffic using TLS.
- SSH: Secure alternative to Telnet.
- SFTP: Transfers files over SSH.
- FTPS: FTP secured with TLS.

## Exam Reminders
A port identifies a service endpoint.
A protocol defines communication rules.
TCP and UDP have separate port-number spaces.
