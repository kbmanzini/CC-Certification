# 07 – VPN and Secure Remote Access

## What is a VPN?
A Virtual Private Network creates a protected communication path across another network, often the internet.

## Types of VPNs

Remote-Access VPN:
Connects an individual user or device to an organization's network.

Site-to-Site VPN:
Connects two separate networks, such as different office locations.

## VPN Benefits

- Encryption.
- Authentication.
- Protected communication across untrusted networks.

## VPN Limitations
A VPN does not automatically make a device trustworthy or protect it from malware.

A compromised endpoint can still put organizational resources at risk.

## Secure Remote Access Practices

- Require strong authentication and MFA.
- Grant access only to necessary resources.
- Keep VPN software updated.
- Monitor remote connections.
- Remove access when no longer authorized.

## Remember
A VPN protects a communication path.
It does not replace endpoint security, firewalls, or monitoring.
