# 08 – Network Threats and Attacks

## Common Threats

- DoS (Denial of Service): Attempts to make a service unavailable.
- DDoS (Distributed Denial of Service): A DoS attack involving multiple systems or sources.
- MITM (Man-in-the-Middle): An attacker positions themselves between communicating parties.
- Malware: Software designed to perform unauthorized or harmful actions.
- Virus: Malware that attaches to a host file or program.
- Worm: Malware capable of self-propagation.
- Trojan Horse: Malicious software disguised as legitimate software.
- Side-Channel Attack: Uses indirect information, such as timing patterns, to infer protected information.

## General Defenses

- Keep systems updated.
- Use endpoint protection.
- Configure firewalls.
- Encrypt sensitive communications.
- Segment networks.
- Monitor logs.
- Maintain tested backups.
- Establish incident-response procedures.
