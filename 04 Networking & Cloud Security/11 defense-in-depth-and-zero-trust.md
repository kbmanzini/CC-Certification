# 11 – Defense in Depth and Zero Trust

## Defense in Depth
Defense in Depth uses multiple layers of security controls so one failed control does not leave an organization unprotected.

Examples:

- Physical Security: Locks, badges, cameras.
- Network Security: Firewalls and segmentation.
- Endpoint Security: Updates and endpoint protection.
- Identity Security: MFA and least privilege.
- Data Security: Encryption and backups.
- Monitoring: Logging and alerting.

## Zero Trust
Zero Trust is a security approach where access is not automatically trusted simply because a user or device is inside a network.

## Core Principles

- Verify explicitly.
- Grant least-privilege access.
- Reassess access as conditions change.
- Segment access.
- Monitor activity.
- Enforce security policies.

## Important Difference

Defense in Depth:
Uses multiple protective layers.

Zero Trust:
Requires explicit verification and avoids implicit trust.

## Remember
Defense in Depth and Zero Trust can be used together.
Zero Trust is not a single product.
