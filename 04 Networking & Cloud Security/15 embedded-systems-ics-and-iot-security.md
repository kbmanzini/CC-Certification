# 15 – Embedded Systems, ICS, and IoT Security

## Embedded Systems
An embedded system is a computer built into a larger device to perform a specific function.

Examples:
- Appliances.
- Vehicles.
- Medical equipment.
- Industrial equipment.

## Industrial Control Systems (ICS)
ICS are systems used to monitor or control industrial processes.

Examples:
- Manufacturing.
- Energy.
- Water treatment.
- Building automation.

## Internet of Things (IoT)
IoT refers to physical devices connected to networks that collect, send, or receive data.

Examples:
- Smart cameras.
- Sensors.
- Connected appliances.
- Environmental monitors.

## Security Challenges

- Limited processing power.
- Limited security features.
- Long device lifecycles.
- Difficult or unavailable updates.
- Default credentials.
- Unnecessary network communication.
- Potential impact on physical processes.

## Defensive Practices

- Maintain an inventory of connected devices.
- Change default credentials.
- Apply vendor updates when available.
- Restrict network access.
- Segment devices appropriately.
- Disable unnecessary services.
- Monitor device behavior.
- Replace devices that reach end of support.

## Safety Reminder
Industrial and operational technology environments can affect physical processes. Testing and changes should only be performed by authorized personnel under approved procedures.

## Remember
IoT security requires inventory, updates, monitoring, access restrictions, and appropriate network isolation.
