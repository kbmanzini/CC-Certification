# 09 – IDS, IPS, and Security Monitoring

## Intrusion Detection System (IDS)
An IDS monitors activity and generates alerts when suspicious patterns or policy violations are identified.

## Intrusion Prevention System (IPS)
An IPS can detect suspicious activity and take action to block or prevent it.

## Common Types

- HIDS: Host-based Intrusion Detection System.
- NIDS: Network-based Intrusion Detection System.
- HIPS: Host-based Intrusion Prevention System.
- NIPS: Network-based Intrusion Prevention System.

## Detection Approaches

Signature-Based:
- Compares activity with known threat patterns.
- Useful for recognizing known threats.

Anomaly-Based:
- Looks for unusual activity compared with a normal baseline.
- Can identify unexpected behavior.

## Important Terms

- Alert: Notification that something may need attention.
- False Positive: Benign activity incorrectly identified as suspicious.
- False Negative: Suspicious activity that is not detected.
- Baseline: Reference for normal activity.
- Log: Record of system or network events.

## Remember
IDS = Detect and Alert.
IPS = Detect and Potentially Block.
HIDS = Host.
NIDS = Network.
