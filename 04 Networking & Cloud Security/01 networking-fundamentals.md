# 01 – Networking Fundamentals

## What is a network?
A computer network connects devices so they can communicate and share data or resources.

## Common Network Types

- LAN (Local Area Network): Connects devices in a limited area, such as a home, school, or office.
- WAN (Wide Area Network): Connects networks over large geographic areas.
- WLAN (Wireless LAN): A LAN that uses wireless technology, usually Wi-Fi.
- PAN (Personal Area Network): Connects personal devices over a short range, often using Bluetooth.

## Common Network Devices

- Router: Connects different networks and forwards packets.
- Switch: Connects devices within a LAN.
- Wireless Access Point: Allows wireless devices to connect to a network.
- Firewall: Allows or blocks network traffic based on security rules.
- Modem: Connects a network to an internet service provider.

## Important Terms

- Bandwidth: Maximum capacity of a network connection.
- Throughput: Amount of data successfully transferred over time.
- Latency: Delay as data travels across a network.
- Protocol: A set of rules for communication.
- Packet: A unit of data transmitted across a network.

## Remember
Routers connect networks.
Switches connect devices within a LAN.
Access points provide Wi-Fi.
Firewalls enforce traffic rules.
