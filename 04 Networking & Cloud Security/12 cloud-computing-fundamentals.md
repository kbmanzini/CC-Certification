# 12 – Cloud Computing Fundamentals

## What is cloud computing?
Cloud computing provides on-demand access to computing resources such as servers, storage, networks, and applications.

## Five Common Characteristics

1. On-Demand Self-Service:
   Customers can provision resources when needed.

2. Broad Network Access:
   Services are available over networks using common client platforms.

3. Resource Pooling:
   Provider resources serve multiple customers through shared infrastructure.

4. Rapid Elasticity:
   Resources can scale up or down quickly.

5. Measured Service:
   Usage can be monitored, measured, and billed or reported.

## Benefits

- Flexible capacity.
- Faster provisioning.
- Access to computing resources without owning all hardware.
- Potentially lower upfront costs.

## Security Considerations

- Configure access controls carefully.
- Protect credentials.
- Encrypt sensitive data.
- Monitor cloud activity.
- Understand data storage locations.
- Secure cloud storage configurations.
- Maintain appropriate backups.

## Remember
Cloud computing changes how resources are delivered.
It does not remove the need for security.
