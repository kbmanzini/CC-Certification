# 13 – Cloud Service and Deployment Models

## Cloud Service Models

IaaS – Infrastructure as a Service
- Provider supplies virtual machines, storage, and networking.
- Customer generally manages operating systems, applications, and data.

PaaS – Platform as a Service
- Provider supplies a managed application platform.
- Customer focuses on application code and data.

SaaS – Software as a Service
- Provider delivers a complete application.
- Customer manages appropriate use, access, and data handling.

Memory Aid:
IaaS = Infrastructure.
PaaS = Platform.
SaaS = Software.

## Cloud Deployment Models

Public Cloud:
Services offered over provider infrastructure to customers.

Private Cloud:
Cloud infrastructure dedicated to one organization.

Hybrid Cloud:
Combines private infrastructure or cloud with public cloud services.

Community Cloud:
Shared by organizations with common requirements.

## Important Difference
Service models describe WHAT kind of service is provided.

Deployment models describe HOW the cloud environment is organized.

## Remember
Customers retain security responsibilities in every cloud service model.
