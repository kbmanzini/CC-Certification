# 06 – Wireless and Bluetooth Security

## Wi-Fi Basics
Wi-Fi connects devices through wireless radio signals and access points.

## Wireless Security Practices

- Use WPA2-AES or WPA3 where supported.
- Use strong, unique Wi-Fi passwords.
- Change default administrator credentials.
- Update access-point firmware.
- Separate guest networks from internal networks.
- Disable unnecessary wireless features.
- Monitor for unauthorized access points.

## Common Wireless Risks

- Eavesdropping: Unauthorized observation of communications.
- Rogue Access Point: Unauthorized access point connected to or impersonating a network.
- Evil Twin: Fraudulent access point imitating a legitimate Wi-Fi network.
- Weak Encryption: Makes communications easier to compromise.
- Untrusted Public Wi-Fi: May expose users to monitoring or deceptive networks.

## Bluetooth Security

- Turn Bluetooth off when not needed.
- Keep devices updated.
- Avoid unexpected pairing requests.
- Remove unused device pairings.
- Use appropriate visibility and pairing settings.

## Remember
Wireless security requires encryption, secure configuration, monitoring, and user awareness.
